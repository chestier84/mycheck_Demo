🚀 Desplegar Datafix en Render

¿Qué es Render?

Render es una plataforma de hosting en la nube moderna que permite desplegar aplicaciones sin necesidad de configurar servidores. Es similar a Heroku, Railway y AWS, pero con:

  • ✅ Deploy automático desde GitHub
  • ✅ Soporta docker-compose
  • ✅ Base de datos PostgreSQL gratuita
  • ✅ SSL/HTTPS automático
  • ✅ Interfaz visual muy intuitiva
  • ⚠️ No soporta Oracle directamente (usa PostgreSQL)
  • ⚠️ Tier gratuito limitado

Comparativa: Render vs Otros

Plataforma Precio Inicial Docker-Compose BD Incluida Facilidad
Render $7/mes (web) ❌ No (manual) ✅ PostgreSQL ⭐⭐⭐⭐

ℹ️ Para Datafix: Si quieres usar Oracle, mejor opción es Railway o AWS. Si puedes migrar a PostgreSQL, Render es excelente.

✅ Opción 1: Render + PostgreSQL (Recomendado)

Por qué: Render es muy fácil, PostgreSQL es mucho más ligero que Oracle, y el costo es mínimo.

Paso 1: Preparar Repositorio GitHub

1 Asegúrate de que tu repo esté en GitHub (public o private)
cd "C:\...\1 Datafix Oracle automatico" git init git add . git commit -m "Datafix ready for Render" git branch -M main git remote add origin https://github.com/TU_USUARIO/datafix-render.git git push -u origin main

Paso 2: Crear Cuenta en Render

2 Ve a render.com y crea cuenta con GitHub
  • Haz clic en "Sign up"
  • Selecciona "Sign up with GitHub"
  • Autoriza Render a acceder a tus repos

Paso 3: Crear Base de Datos PostgreSQL (Gratis)

3 En Render Dashboard → New + → PostgreSQL
  • Name: datafix-db
  • Region: Selecciona más cercano
  • PostgreSQL Version: 14
  • Plan: Free (gratuito)
  • Create Database

⏱️ Espera 2-3 minutos mientras se crea

Paso 4: Copiar Connection String

4 Una vez creada, copia la conexión

En la página de la BD → Info → External Database URL
Verá algo como: postgresql://user:pass@host:5432/dbname

Paso 5: Crear Web Service (Backend)

5 Render Dashboard → New + → Web Service
  • Repository: Selecciona tu repo de GitHub
  • Branch: main
  • Runtime: Python 3
  • Build Command: pip install -r requirements.txt
  • Start Command: uvicorn main:app --host 0.0.0.0 --port 10000
  • Plan: Free (gratuito) o Pay-as-you-go ($7/mes)
  • Create Web Service

Paso 6: Agregar Variables de Entorno

6 Web Service → Environment → Add Environment Variable
DATABASE_URL=postgresql://user:pass@host:5432/dbname PYTHONUNBUFFERED=1

Pega la conexión PostgreSQL que copiaste en el Paso 4

✅ Backend desplegado. URL pública generada automáticamente (p.ej. https://datafix-backend.onrender.com)

Paso 7: Crear Web Service (Frontend)

7 Render Dashboard → New + → Web Service
  • Repository: Mismo repo
  • Build Command: echo "Frontend ready"
  • Start Command: nginx -g 'daemon off;'
  • Plan: Free
⚠️ Para el frontend, necesitas un Dockerfile específico. Ver Paso 8.

Paso 8: Crear Dockerfile para Frontend (si no existe)

8 Crea archivo frontend.Dockerfile en la raíz
FROM nginx:alpine COPY datafix_oracle.html /usr/share/nginx/html/index.html COPY backend/nginx.conf /etc/nginx/conf.d/default.conf EXPOSE 80 CMD ["nginx", "-g", "daemon off;"]

⚠️ Opción 2: Render + Oracle (Complejo)

No Recomendado: Render no tiene soporte nativo para Oracle. Necesitarías:
  • Usar Oracle Cloud Database (pago, ~$20-50/mes)
  • O ejecutar Oracle en otra plataforma (AWS RDS, etc.)
  • O migrar a PostgreSQL (recomendado)

🔄 Migrar de Oracle a PostgreSQL

Ventajas:

  • Gratis (PostgreSQL en Render es gratis)
  • Más ligero (menos recursos)
  • Mejor soporte en Render
  • Código Python prácticamente sin cambios

Cambios en requirements.txt:

# Cambiar: cx-Oracle==8.3.0 # Por: psycopg2-binary==2.9.0

🐳 Opción 3: Render + Tus Imágenes de Docker Hub

ℹ️ Render puede desplegar imágenes Docker directamente desde Docker Hub

Paso 1: Render Dashboard → New + → Web Service

1 Deploy with image URL
  • Image URL: chestier84/datafix-backend:latest
  • Port: 8000
  • Create Web Service

Paso 2: Agregar Variables de Entorno

2 Environment → Add Environment Variable
DATABASE_URL=postgresql://user:pass@host:5432/dbname ORACLE_HOST_OVERRIDE=oracle.tu-dominio.com ORACLE_PWD=OraclePwd1
✅ Listo. Render auto-descarga y ejecuta tu imagen cada vez que la actualizas en Docker Hub.
