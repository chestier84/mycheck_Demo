⚖️ Catálogo de Reglas de Auditoría

🚧 Sentencias con COMMIT implícito en DRY RUN

Estas sentencias commitean automáticamente en Oracle y romperían el SAVEPOINT del DRY RUN. Cuando una está activa, el backend la omite (no la ejecuta) durante la simulación. Al desactivarla, la sentencia SÍ se ejecutará en el DRY RUN — bajo tu propio riesgo.

Cambios se guardan automáticamente en este navegador. Se envían al backend en cada DRY RUN.
